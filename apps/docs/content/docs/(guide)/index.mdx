## What is Clowder

Clowder is a self-hosted PaaS (Platform as a Service) inspired by [Railway](https://railway.com) and built on top of [Uncloud](https://uncloud.run). It gives you one dashboard to monitor, manage and deploy [Docker Images](/docs/deploy/images), [Databases](/docs/deploy/databases), [microVM Sandboxes](/docs/deploy/sandboxes), [S3 Buckets](/docs/deploy/buckets) and many [Templates](/docs/deploy/templates) to pick from.

## Why Clowder

I wasn't happy with any self-hosted PaaS. I wanted a simple UI that I can count on (Railway was on point). I found Uncloud but it didn't have a webui from where I could manage it, so I built Clowder, which uses a canvas, like Railway.

"Why not just use Railway?" It can get very expensive. For example my setup would cost way over $500/mo to run on Railway but I only pay ~$40 to [BelgiumVM](https://irazz.click/belgiumvm) and also get much better performance, security and control.
